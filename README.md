# Corporate Network Infrastructure Security
Corporate Network Infrastructure & Security
A secure enterprise network infrastructure designed and implemented using Cisco Packet Tracer.
Project Overview
This project demonstrates the design, configuration, and security of a corporate network using VLAN segmentation, trunking, access control, and network security controls.
Network and Security Features
VLAN Segmentation
802.1Q Trunking
Inter-VLAN Routing
Access Control Lists (ACLs)
SSH Remote Management
Port Security
DHCP Snooping
Spanning Tree Protocol (STP)
Connectivity and Security Testing
VLAN Configuration
The network is divided into the following VLANs:
VLAN 10: USERS — 192.168.10.0/24
VLAN 20: IT — 192.168.20.0/24
VLAN 30: SOC — 192.168.30.0/24
VLAN 40: SERVERS — 192.168.40.0/24

Testing
Connectivity was tested between different VLANs to verify the configured network security policies and access restrictions.
The tests confirmed that permitted traffic was allowed and restricted traffic was blocked according to the configured ACL rules.
